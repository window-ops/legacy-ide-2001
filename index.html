O satiră funcțională a programei analitice de TIC din anii 2000, care refuză orice construcție introdusă după decembrie 2001 și care simulează un backend QNX scris de o echipă IT foarte neglijentă.

Avertisment de fidelitate
Această aplicație nu este o reprezentare exactă a niciunuia dintre sistemele de operare imitate. Interfața QNX Photon, ecranele de pornire, comenzile de shell și descrierile de comportament sunt simplificate, modificate sau pur inventate.

Despre QNX: sistemul QNX a luat de-a lungul timpului mii de forme. Photon microGUI a apărut pe Netpliance iOpener, pe automate industriale, în mașini, pe BlackBerry 10, în echipamente medicale. Niciuna dintre aceste implementări nu arată ca cea din această aplicație. Imitația aleasă aici este una dintre multele forme posibile, nu este QNX-UL și nu trebuie folosită ca referință tehnică.

Despre Windows Server 2003: Microsoft a livrat o singură versiune principală iar imitația acesteia nu este fidelă. Pictogramele sunt redesenate, dialogurile sunt simplificate, comportamentul backend (validarea prin IIS, jurnalizarea prin Event Viewer, registry editor cu trei chei funcționale) este o invenție narativă pentru a sprijini satira, nu o copie a comportamentului real.

Mărcile Microsoft Windows, Windows Server 2003, QNX, Photon, și orice alte denumiri comerciale aparțin proprietarilor lor. Folosirea lor aici este în scop de referință și satiră, fără afiliere sau aprobare.

Precizare
Acest proiect nu este un produs oficial, nu are nicio legătură cu Ministerul Educației și Cercetării și nu este aprobat sau finanțat de vreo instituție publică. Este o lucrare personală de satiră.

Satira ar fi fost demult depășită dacă profesorii ar fi fost mai puțin stricți, dacă unitățile de învățământ s-ar fi modernizat și dacă programele școlare ar fi fost actualizate. În loc de asta, iată-ne aici.
